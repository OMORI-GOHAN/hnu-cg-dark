# HNU CG Dark

为湖南大学 CourseGrading 系统提供暗色主题的浏览器扩展，采用接近 GitHub Dark 的配色。

适用网站：<https://cg.hnu.edu.cn/>。

## 功能

- 登录页：登录卡片、自动填充输入框、统计面板。
- 作业页：作业卡片、侧栏、题干、填空输入框、题目预览弹窗。
- 编程题：题目内容、文件上传控件、提交代码预览。
- 考试回顾：题干、选项及部分富文本内联样式。
- 论坛：帖子背景、回复统计条及按钮。
- 个人信息：表单背景、输入控件。
- 评判详情：代码风格检查、性能剖析报告与导航标签。
- 算法可视化：DSV 控制栏及画布的暗色适配。

具体效果取决于页面结构和题目内容，尚未覆盖原站的所有页面及状态。

## 安装

支持加载 Manifest V3 扩展的 Chrome、Edge 等 Chromium 浏览器，无需构建或安装依赖。

1. 下载或克隆项目，保留完整目录结构；若下载 ZIP，请先解压。
2. 打开浏览器扩展管理页：Chrome 为 `chrome://extensions/`，Edge 为 `edge://extensions/`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
5. 打开或刷新 CG 页面。

扩展启用后自动应用主题，目前没有单独的主题开关。需要恢复原站外观时，在扩展管理页停用扩展并刷新 CG 页面。

## 更新与调试

修改或更新项目文件后：

1. 在扩展管理页点击 HNU CG Dark 的「重新加载」。
2. 刷新已打开的 CG 页面，使其重新加载主题。
3. 重新打开需要检查的弹窗或代码预览。

若没有生效，请检查扩展是否启用、加载目录是否正确，以及页面地址是否属于 `https://cg.hnu.edu.cn/`。

## 项目结构

```text
hnu-cg-dark/
├── manifest.json    # 扩展配置、网站匹配范围与 CSS 注入
├── README.md
└── src/
    ├── theme.css    # 配色变量、组件适配及页面补充规则
    └── rich-text.js # 题干计算颜色检测与动态适配
```

扩展注入 CSS 和本地题干适配脚本 `src/rich-text.js`。脚本只检查已知题干容器的计算颜色，为中性浅色背景和深色文字添加主题标记，并监听动态内容；不修改题目文字或答案。没有后台脚本、网络请求代码或数据存储逻辑。配置中的 `all_frames: true` 使匹配 CG 域名的嵌入页面也能加载主题；它不会让其他域名的 iframe 自动获得主题。

自动适配会跳过图片、画布、代码块、链接、表单控件、编辑器和公式，保留明显的彩色标记。特殊内容可通过 `data-cg-dark-preserve` 属性排除。旧 CSS 补丁仍作为兼容兜底；新增容器、非中性背景、图片内白底及内联 `!important` 仍可能需要专门适配。

## 维护约定

### 配色

优先复用 `theme.css` 开头 `:root` 中的变量：

| 变量 | 用途 |
| --- | --- |
| `--gh-bg` | 页面与题干背景 |
| `--gh-bg-secondary` | 卡片、弹窗和代码背景 |
| `--gh-bg-tertiary` | 输入控件、强调区域 |
| `--gh-text` | 正文与标题 |
| `--gh-text-secondary` | 辅助说明 |
| `--gh-border` | 分隔线与边框 |
| `--gh-blue-light` | 链接与焦点提示 |

### 添加规则

- 每个属性独立一行，使用四空格缩进，保留简短的分区和用途注释。
- 先用浏览器开发者工具查看实际生效的样式，再针对组件添加覆盖。
- 优先限定在题干、报告或特定组件内，避免全局 `*`、全局图片反色等宽泛规则。
- 原站存在内联颜色及 Bootstrap 的 `!important`；仅在必要时使用 `!important`，并注意选择器优先级。
- 整理重复规则时保留有效的覆盖顺序；不要随意合并、移动不同页面的补丁。
- 颜色适配与布局修改分别检查。现有文件包含部分尺寸、定位和显示状态规则，调整时需确认原站交互正常。

### 图片与画布

主页照片、校徽和验证码保持原色。当前 `#activeActionDIV` 内的题目图片仍采用反色处理，彩色图片可能因此失真。可对不需要反色的题图添加 `no-dark-filter` 类；普通使用者需要通过开发者工具或后续脚本实现，扩展目前没有逐图切换界面。

DSV 动画画布使用 `invert(1) hue-rotate(180deg)`，因为画布内绘制的文字无法通过 CSS `color` 改变。这会改变绘制颜色，修改后应检查文字、连线和动画状态是否仍可区分。

### 回归检查

更新主题后，建议依次检查：

- 登录页的图片、统计数字、自动填充和验证码。
- 作业列表、填空题、带图片或富文本的题目，以及题目弹窗。
- 提交代码预览、评判详情中的代码风格检查和性能剖析。
- 论坛、个人信息表单及算法可视化。
- 常用窗口宽度下的换行、滚动、焦点和按钮状态。

无需为检查主题提交作业、修改个人资料或发送论坛内容。

## 当前限制

- AI 助手等来自其他域名的嵌入页面不在匹配范围内。
- 富文本适配包含对特定内联颜色的匹配，新的颜色写法或原站结构变化可能需要补充规则。
- 部分代码高亮被统一为浅色文字，尚未提供完整的语法高亮主题。
- 原站部分页面在窄窗口下存在拥挤或横向溢出，主题尚未完成全面的响应式布局适配。
- 当前没有自动化视觉回归测试，页面效果需要浏览器验证。

本项目为非官方外观扩展，与 CourseGrading 官方无隶属关系。
